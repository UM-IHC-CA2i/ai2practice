Step 1: Clean the data

Raw data is messy. Before training, someone checks it and removes examples that would teach the model the wrong thing. This is called data cleaning. A model cannot tell a good example from a bad one: it learns from all of them.

Cleaning also means making every example the same shape. These digits were all resized to 28 by 28 pixels and centered, much as X-rays are resized and adjusted before training.

In radiology the same problems turn up: a wrong label pulled from a report, the same study saved twice, an underexposed film, a cropped image, or a knee X-ray in a chest dataset.

Step 2: Split the data

Next the clean data is divided. Most of it becomes the training set: the examples the model learns from. A smaller part is locked away as the test set and used once, at the end, to see how the model does on examples it has never seen. That score predicts how it will do on new patients. Many teams also keep a third part, the validation set, to check progress while they build.

One rule matters a lot in medicine: split by patient, not by image, because one patient often has several images.

Step 3: Choose how it learns

There are three main ways a model can learn. Which one fits depends on the data you have.

Supervised learningLearns from examples that come with the right answer (labels). Real example: detecting diabetic retinopathy from graded retinal photos.
Unsupervised learningGets data with no labels and finds groups or patterns on its own. Real example: grouping ICU patients into four sepsis phenotypes that nobody had defined beforehand.
Reinforcement learningLearns by trial and error, getting a reward for good outcomes, like learning a game. Real example: the "AI Clinician", which learned fluid and vasopressor strategies in sepsis from past ICU records.

Step 4: Train the model

A model is a set of adjustable numbers called parameters; think of them as knobs. Training means: show an example, let the model guess, check the guess against the label, and nudge the knobs so the next guess is a little better. Then repeat, thousands of times.

Step 5: Models that read images

The network above learned where ink usually is, so moving a digit fools it. A convolutional neural network (CNN) slides small windows across the picture to find edges, then builds edges into shapes and parts, wherever they are. CNNs are behind most imaging AI, including chest X-ray tools. "Deep learning" simply means a network with many layers. This one is already trained.

Knowledge check

Answer each question to continue. Any answer is fine; read the explanation.

A hospital has three chest X-rays from each of 1,000 patients. Which split gives an honest test score?

Split by patient. If one patient's images land on both sides, the model may recognize the patient rather than the disease, and its test score will look better than it will be on new patients. Testing on training images tells you nothing about new patients.

Which type of learning needs every training example to come with the right answer?

Supervised learning learns from labeled examples, like X-rays each marked fracture or no fracture, or the digits in this lesson. Unsupervised learning has no labels, and reinforcement learning learns from rewards rather than answers.

In the digit network, what happened when each nudge was too big?

Each nudge overshoots, undoing what earlier examples taught, so the score bounces up and down. Too small a nudge barely learns. The nudge size, the learning rate, is one of the settings developers tune while building a model.

Key takeaways

  • Clean the data first: a model learns from bad examples as readily as from good ones.
  • Train on the training set, test on a test set it never saw, and split by patient so the test is fair.
  • Supervised learning uses labels; unsupervised finds groups; reinforcement learns from rewards. Most radiology AI is supervised.
  • Training is: guess, check, nudge the knobs (parameters), repeat. The size of each nudge is the learning rate.
  • A CNN finds edges, then shapes, then parts, anywhere in the image. "Deep" means many layers.
