Key Concepts

Supervised Learning — A type of machine learning where you provide labeled examples (input + correct answer) and the model learns to predict the answer for new inputs. Both logistic regression and decision trees are supervised classifiers.

Train/Test Split — Dividing your data so the model learns from one portion (training set) and is evaluated on a held-out portion (test set). Testing on training data gives artificially high performance because the model has memorized the answers.

Pre-Trained Model — A neural network that has already been trained on a large dataset (e.g., ImageNet with 1.2 million images). You can use it directly or fine-tune it on a smaller, specialized dataset. This approach is called transfer learning.

Image Segmentation — Labeling every pixel in an image as belonging to a specific class (e.g., hand vs. background, tumor vs. normal tissue). Unlike classification, which assigns one label to the whole image, segmentation produces a pixel-level map.

Convex Hull — The smallest convex polygon that encloses a set of points. In this module, we use the convex hull of hand landmark points to approximate the outline of the hand for segmentation.

Why do we split data into separate training and test sets?
The test set simulates new, unseen data. If you evaluate on training data, the model appears to perform well because it has memorized the answers. Testing on held-out data reveals true generalization ability.

Question 4 of 5
What is the difference between image classification and image segmentation?
Classification answers "what is in this image?" with a single label. Segmentation answers "where is each object?" by labeling every pixel. In radiology, segmentation is used to outline tumors, measure organ volumes, and isolate regions of interest.
