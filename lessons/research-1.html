Setting Up Your AI Research Environment

GitHub, Google Colab, Python, and your first data analysis

Overview

Estimated time: 45–60 minutes

Before you can evaluate an AI model or conduct research on AI in radiology, you need to know how to work with data programmatically. Spreadsheets work for small tasks, but AI research requires tools that can handle large datasets, reproduce analyses exactly, and share work with collaborators.

In this module, you will set up a research environment used by AI researchers worldwide: GitHub for version control and collaboration, Google Colab for running code in the cloud, and Python for data analysis. By the end, you will have analyzed a real-format radiology AI dataset and committed your work to your own GitHub repository.

No prior programming experience is required. Every step is guided.

What you need before starting
  • A computer with internet access and a web browser (Chrome recommended)
  • A personal email address (for creating accounts)
  • Completion of Lesson 1 (the three AI competency risks)

Walkthrough

1

Create a GitHub Account

GitHub is the standard platform for sharing code and data in research. Your GitHub account serves as a portfolio of your computational work, and every change you make is tracked with timestamps and your username.

  1. Go to github.com/join
  2. Create an account with your preferred email
  3. Choose a professional username (you may use this on publications or CVs)
  4. Complete the email verification

If you already have a GitHub account, skip to Step 2.

Why this matters for AI research

Every published AI study links to a GitHub repository containing code and data. Learning GitHub now means you can access, reproduce, and build on published research rather than relying on others' summaries.

2

Fork the Starter Repository

Forking creates your own copy of a repository. Changes you make to your fork do not affect the original, so you can experiment freely.

  1. Go to the starter repository: github.com/UM-IHC-CA2i/Bootcamp-AI-for-Medical-Imaging
  2. Click the Fork button in the top-right corner
  3. On the "Create a new fork" page, keep the defaults and click Create fork
  4. You now have your own copy at github.com/YOUR-USERNAME/Bootcamp-AI-for-Medical-Imaging

Your fork is linked to your account and timestamped, creating a verifiable record of your work.

Why this matters for AI research

Forking is how researchers build on each others' work. When a paper publishes their AI model code, you fork it to run their experiments yourself. This is the foundation of reproducible science.

3

Open the Notebook in Google Colab

Google Colab is a free, cloud-based environment for running Python code. It requires no installation — everything runs in your browser. It is the same tool used by researchers at Google, Stanford, and major AI labs.

  1. Go to colab.research.google.com (sign in with a Google account if prompted)
  2. Click Open notebook
  3. Select the GitHub tab
  4. Paste your fork URL: https://github.com/YOUR-USERNAME/Bootcamp-AI-for-Medical-Imaging
  5. Click lesson-notebooks/Research_Module_1.ipynb to open it

You should now see the notebook with code cells and instructions. Each cell can be run independently by clicking the play button or pressing Shift + Enter.

4

Work Through the Notebook

The notebook teaches you Python from scratch and then uses it to explore a dataset of 60 radiology studies. Work through it in order — each section builds on the last.

Part 1 — Python Basics:

  • Variables and types (strings, numbers, booleans)
  • Lists and how to access items
  • For loops to repeat actions
  • Functions to write reusable code
  • Conditionals (if/else) for decisions

Part 2 — Loading Data:

  • Load the dataset directly from your GitHub fork
  • Explore it with .head(), .shape, and value_counts()
  • Create a bar chart showing studies by modality

Important: In the cell that loads data, replace YOUR-USERNAME with your actual GitHub username.

5

Complete the “Your Turn” Tasks

Part 3 of the notebook contains four short tasks that apply what you learned. Each produces unique output based on your choices:

  • Task 1: Create variables with your name and favorite modality
  • Task 2: Write a for loop to print body regions
  • Task 3: Use value_counts() to count AI-flagged studies
  • Task 4: Create a bar chart of studies by body region
Why this matters for AI research

These basic skills — storing values, looping through data, counting categories, and making charts — are the building blocks of every AI research analysis. In the next module, you will use them to calculate real evaluation metrics.

6

Download Your Completed Notebook

Once you have completed all four tasks and run the completion record cell at the bottom, download your notebook from Colab:

  1. In Colab, go to File → Download → Download .ipynb
  2. The file will save to your computer's Downloads folder
7

Upload and Commit to GitHub

Now upload your completed notebook to your forked repository on GitHub:

  1. Go to your forked repository: https://github.com/YOUR-USERNAME/Bootcamp-AI-for-Medical-Imaging
  2. Click the Code tab at the top of the page
  3. Click Add file, then select Upload files
  4. Drag and drop your downloaded .ipynb file into the upload area
  5. In the commit message box, type: Completed Research Module 1
  6. Make sure “Commit directly to the main branch” is selected
  7. Click Commit changes

Your commit is now permanently recorded on GitHub with your username, timestamp, and the exact changes you made.

8

Submitting Your Work (After All Modules)

After you have completed and uploaded all 5 research modules, submit your work for review by opening a pull request:

  1. Go to your fork: https://github.com/YOUR-USERNAME/Bootcamp-AI-for-Medical-Imaging

Why pull requests matter

Pull requests are how researchers and developers propose changes for review. Your instructor can see exactly what you changed, leave comments, and verify your work — all in one place. This is the same process used in open-source software and collaborative research.

Key Concepts Introduced

Version Control (Git/GitHub) — A system that tracks every change to a set of files over time. Each change is recorded as a "commit" with a timestamp, author, and description. This allows researchers to reproduce any prior state of their work and collaborate without overwriting each other's changes.

Jupyter Notebook — An interactive document that combines code, output, and text in a single file. Researchers use notebooks to document their analysis step-by-step, making it easy for others to follow and reproduce their work. Google Colab is a cloud-hosted version of Jupyter.

Variable — A named container that stores a value. In Python, you create one with x = 5. Variables can hold numbers, text, lists, or more complex data structures. They are the basic building blocks of any program.

pandas DataFrame — A table of data in Python, similar to a spreadsheet. Each column has a name, each row is a record. Commands like .head(), .shape, and .value_counts() let you quickly understand what the data contains without scrolling through every row.
