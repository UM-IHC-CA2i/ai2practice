What is AI?

AI Around You

What AI is, how it differs from a hand-written rule, and what a real AI model sees when it looks at a picture

Overview

You do not need any background in computers for this lesson. You will start with tools you already use every day, see the one idea that separates "AI" from an ordinary program, and then try five real AI models yourself, right in your browser. It takes about 15 minutes.

By the end of this lesson you can:

  • Define AI in one sentence.
  • Tell a rule a person wrote apart from a model that learned from examples.
  • Place AI, machine learning, deep learning and generative AI in one picture.
  • Describe what an AI model gets right and wrong, from your own experiments.

You already use AI every day

A simple working definition: artificial intelligence (AI) is a computer system that does a task we would normally say needs human intelligence, such as recognizing a face, understanding speech or guessing what you meant to type. By that definition you probably used a dozen AI tools before breakfast. For each one, the useful question is not "is it smart?" but "did a person write the rules, or did it learn from examples?"

Rules vs learning

There are two broad ways to get a computer to do a job. The first is to write the rule yourself: "if the word is not in the dictionary, underline it," or "if the room is below 20 degrees, turn on the heat." The computer follows the rule exactly. It is predictable and easy to check, but someone has to be able to write the rule down.

Now try writing a rule for "what does a dog look like?" Dogs come in every size and color, photographed from every angle in every kind of light. Nobody can write that rule. Instead, you show the computer thousands of photos, each labeled "dog" or "not dog," and let it find the pattern on its own. This is called training. What comes out is a model, and the whole approach is called machine learning.

How the terms fit together

You will hear AI, machine learning, deep learning and generative AI used as if they mean the same thing. They don't: each one sits inside the one before it. Tap a ring to see what it means and where the tools you just tried belong.

Artificial intelligence

Any computer system doing a task that normally needs human intelligence, including rules a person wrote.

Everyday examples: a chess computer from the 1990s, a classic spell checker

Machine learning

AI that learns patterns from examples instead of following rules a person wrote.

Everyday examples: spam filters, Netflix recommendations

Deep learning

Machine learning that uses neural networks with many layers. Most modern image and speech AI, including every model in the lab above. Lesson 1.3 explains the layers.

Everyday examples: face unlock, Siri, Google Photos

Generative AI

Deep learning that creates new content: text, images or audio. Large language models (LLMs) are generative AI.

Everyday examples: ChatGPT, image generators

So every deep learning model is machine learning, and every machine learning model is AI, but not the other way around. A thermostat rule counts as AI under the broad definition, but it never learned anything.

What AI is not

Your experiments above show the three most important limits. AI is not thinking. A model finds statistical patterns in data; the hand model has no idea what a hand is for. AI is not general. Each model does the job it was trained for and nothing else, and it will not warn you when you ask it to step outside that job. AI is not always right. Every model makes mistakes, sometimes while sounding sure of itself. Lessons 1.4 and 1.5 show how to measure those mistakes and predict when they happen.

Knowledge check

Answer each question to continue. Any answer is fine; read the explanation.

A new kind of scam email starts getting past two spam filters. Filter A follows rules a person wrote. Filter B learned from examples. What is the usual way to fix Filter B?

A learned model changes by learning from new labeled examples, not by someone editing a rule. Filter A is the one you fix by writing a new rule. Learned filters only keep up if someone keeps feeding them fresh, correctly labeled examples.

You give the "Name it" model a chest X-ray and it answers "fountain, 77%." What is the best explanation?

A model can only choose from what it was trained on, and it has no built-in way to say "I don't know." The 77% is how sure the model is, not the real chance it is right: here it is very sure and completely wrong. This is why a medical AI tool must be tested on exactly the kind of images it will see in practice.

ChatGPT is generative AI. Which of these is also true about it?

The terms nest: generative AI sits inside deep learning, which sits inside machine learning, which sits inside AI. So ChatGPT is all four. The image models in the lab are deep learning too; they just predict labels and points instead of creating new text.

Key takeaways

  • AI is a computer system doing a task that normally needs human intelligence.
  • A rule is written by a person; a machine learning model learns its own pattern from labeled examples.
  • AI contains machine learning, which contains deep learning, which contains generative AI.
  • Models are narrow, they do not understand, and they can be confidently wrong.
