Lab 3 · Core line

Evaluating an AI tool

The question

A pneumothorax detector for chest X-rays reports 94% sensitivity in its FDA submission. What does it actually get on local data, and does it work equally well at both of a hospital's sites?

By the end you can

  • Build a confusion matrix from model scores and a threshold
  • Calculate sensitivity, specificity, PPV and NPV, and explain how prevalence changes them
  • Draw an ROC curve and choose a threshold for a clinical setting
  • Compare performance across subgroups

What this shows: every notebook task is tagged with one of six modes. Early labs lean on writing code yourself; later labs lean on reusing your own code, directing an AI and checking its work. This keeps beginners learning the basics and shows how research code is really written now.
