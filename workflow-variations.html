Radiology Workflow — Content Variations

Same chevron strip, six different content panel layouts. Pick your favorite.

Variation A
Two-Column: Text + Sidebar Media
Text on the left, stacked image/video slots on the right. Links below media.
Variation B
Full-Width Stacked: Header Bar + Text + Media Row
Colored header bar up top, prose underneath, three-column media grid at the bottom.
Variation C
Tabbed: Overview / Media / Learn More
Content split into tabs so nothing feels overwhelming. Interpretation types shown as a vertical list.
Variation D
Callout Style: Colored Left Border
Clean left border accent. Teaching-point aside box. Compact media thumbnails in a row.
Variation E
Magazine Spread: Big Image + Two Columns
Large hero image/video slot on top, text in two columns below.
Variation F
Minimal Prose: Single Column, Clean Text
Just well-written text, a thin divider, and compact resource cards. No visual clutter.
